# Анализ проблем и предложения по улучшению (AS-IS / TO-BE)

## Цель

Упростить путь потенциального заказчика от знакомства с услугами строительной компании до обращения через сайт.

AS-IS — выявленные проблемы текущего пользовательского сценария.
TO-BE — предлагаемые изменения.

## Сравнение

| AS-IS: выявленная проблема | TO-BE: предлагаемое решение |
|---|---|
| В разных разделах сайта указаны разные телефонные номера без пояснений. | Привести контактные данные к единому виду, указать назначение каждого номера. |
| Телефонные номера отображаются некорректно, их неудобно копировать и использовать для звонка. | Исправить отображение номеров и ссылки для звонка. |
| На странице услуги присутствует посторонний текст, а описание услуг недостаточно конкретное. | Удалить некорректный текст и дополнить описания услуг полезной информацией для заказчика. |
| В материалах о проектах представлены работы только до 2021 года. | Проверить актуальность материалов и дополнить раздел более свежими проектами при их наличии. |
| На сайте несколько форм обратной связи, но их работоспособность не подтверждена. | Проверить отправку заявок из каждой формы и предусмотреть понятное подтверждение обращения. |
| Неизвестно, используется ли указанный WhatsApp для связи с клиентами. | Проверить доступность канала и оставить только актуальные способы связи. |
| Пользователю неясно, когда ожидать ответа после обращения. | Сообщать об успешной отправке заявки и ориентировочном времени ответа. |

## Ожидаемый эффект

Пользователям будет проще найти контакты, получить информацию об услугах и отправить обращение. Это может уменьшить количество затруднений при взаимодействии с сайтом и снизить риск потери заявок.

## Ограничения анализа

Кейс выполнен в рамках учебного задания. Предложенные изменения не внедрялись, поэтому их фактическое влияние на количество обращений не измерялось. Работоспособность форм и мессенджера требует дополнительной проверки.
