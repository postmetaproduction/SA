# Анализ пользовательского сценария сайта строительной компании

## О проекте

Учебный кейс, выполненный в рамках программы повышения квалификации ТГУ «Специалист по информационным системам: оптимизация процессов создания цифровых решений».

Для анализа я выбрала сайт строительной компании «Регионстрой24» и рассмотрела путь потенциального заказчика от знакомства с услугами до обращения в компанию.

## Что я сделала

- Проанализировала контактную информацию, формы обратной связи и содержание страниц сайта.
- Выявила несоответствия в телефонных номерах и проблемы с отображением контактов.
- Обратила внимание на устаревшие материалы и неясность доступности каналов связи.
- Предложила изменения для упрощения обращения заказчика.

## Результат

Составлен перечень выявленных проблем и предложений по улучшению пользовательского сценария. Это аналитические рекомендации, а не внедрённые изменения.

## Контекст

Анализ и предложения выполнены мной самостоятельно с опорой на предыдущий опыт работы с веб-проектами. Учебная работа успешно зачтена преподавателем.
